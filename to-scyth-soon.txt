```sql
-- Core vendor management tables
CREATE TABLE scythe_vendors (
    id INTEGER PRIMARY KEY,
    company_name TEXT NOT NULL,
    email TEXT UNIQUE NOT NULL,
    api_key TEXT UNIQUE NOT NULL,
    stripe_account_id TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    plan_tier TEXT DEFAULT 'starter', -- starter, professional, enterprise
    status TEXT DEFAULT 'active' -- active, suspended, pending
);

-- Product management
CREATE TABLE scythe_products (
    id INTEGER PRIMARY KEY,
    vendor_id INTEGER REFERENCES scythe_vendors(id),
    product_name TEXT NOT NULL,
    product_key TEXT UNIQUE NOT NULL,
    rsa_public_key TEXT NOT NULL,
    rsa_private_key TEXT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    status TEXT DEFAULT 'active'
);

-- License management
CREATE TABLE scythe_licenses (
    id INTEGER PRIMARY KEY,
    product_id INTEGER REFERENCES scythe_products(id),
    license_key TEXT UNIQUE NOT NULL,
    customer_email TEXT NOT NULL,
    customer_name TEXT,
    plan_id INTEGER,
    expires_at DATETIME,
    max_installations INTEGER DEFAULT 1,
    hardware_fingerprint TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    status TEXT DEFAULT 'active', -- active, expired, revoked
    features JSON -- SQLite 3.38+ JSON support
);

-- Payment tracking
CREATE TABLE scythe_transactions (
    id INTEGER PRIMARY KEY,
    vendor_id INTEGER REFERENCES scythe_vendors(id),
    license_id INTEGER REFERENCES scythe_licenses(id),
    stripe_payment_intent_id TEXT,
    amount_cents INTEGER,
    platform_fee_cents INTEGER,
    vendor_payout_cents INTEGER,
    status TEXT, -- succeeded, failed, pending
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Analytics and reporting
CREATE TABLE scythe_license_validations (
    id INTEGER PRIMARY KEY,
    license_id INTEGER REFERENCES scythe_licenses(id),
    hardware_fingerprint TEXT,
    ip_address TEXT,
    user_agent TEXT,
    validation_result TEXT, -- valid, expired, revoked, invalid
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Webhook events
CREATE TABLE scythe_webhook_events (
    id INTEGER PRIMARY KEY,
    vendor_id INTEGER REFERENCES scythe_vendors(id),
    event_type TEXT NOT NULL, -- license.created, license.revoked, payment.succeeded
    payload JSON,
    processed_at DATETIME,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

## TECHNICAL CONSIDERATIONS

### Flask-TSK Integration Points
1. **Authentication**: Use Herd system for vendor authentication
2. **Database**: Research actual database elephant system (NOT Tantor)
3. **WebSockets**: Use Tantor for real-time license status updates
4. **Background Jobs**: Use Horton for payment processing and license generation
5. **Security**: Use Satao for API rate limiting and security monitoring
6. **HTTP Calls**: Use Dumbo for Stripe API and webhook calls

### Performance Requirements
- **License Validation**: <100ms response time
- **Database**: SQLite for individual deployments, PostgreSQL for SaaS
- **Caching**: Redis integration for frequently validated licenses
- **CDN**: Global distribution for license validation endpoints

### Security Requirements
- **RSA-2048**: All licenses cryptographically signed
- **Hardware Fingerprinting**: Privacy-safe system identification
- **API Security**: Rate limiting, HMAC webhook verification
- **Data Protection**: GDPR compliance, data encryption

### Scalability Considerations
- **Multi-tenant Architecture**: Vendor isolation and data separation
- **Auto-scaling**: Handle traffic spikes during product releases
- **Global Distribution**: CDN for worldwide license validation
- **Database Sharding**: Scale beyond single database limits
