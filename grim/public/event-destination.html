Event Destination Setup

Configure Stripe webhooks to enable automatic license tier management and payment processing for Grim Reaper.

🚀 Stripe Webhook Configuration

1

Access Stripe Dashboard

Log into your Stripe Dashboard and navigate to the webhooks section.

Open Stripe Dashboard
2

Add Endpoint

Click "Add endpoint" and configure the following settings:

Endpoint URL: 
https://your-domain.com/api/billing/webhook
Events to send:
  • invoice.payment_succeeded
  • invoice.payment_failed
  • customer.subscription.deleted
  • customer.subscription.updated

⚠️ Important

Replace your-domain.com with your actual domain where Grim Reaper is hosted.

3

Get Webhook Secret

After creating the endpoint, copy the webhook signing secret:

whsec_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

✅ Webhook Secret Format

The secret starts with whsec_ followed by a long string of characters.

4

Configure Environment

Add the webhook secret to your environment variables:

export STRIPE_WEBHOOK_SECRET="whsec_your_webhook_secret_here"

Or add it to your ~/.bashrc file:

echo 'export STRIPE_WEBHOOK_SECRET="whsec_your_webhook_secret_here"' >> ~/.bashrc
source ~/.bashrc

🧪 Testing Your Webhook

Test Webhook Delivery

In the Stripe Dashboard, you can test your webhook by sending test events:

Test Events Available:
  • invoice.payment_succeeded
  • invoice.payment_failed
  • customer.subscription.deleted

Click "Send test webhook" in your Stripe Dashboard to verify the endpoint is working correctly.

🔒 Security Features

✅ Webhook Signature Verification

When STRIPE_WEBHOOK_SECRET is set, the system verifies webhook signatures to prevent spoofing attacks.

✅ Automatic License Management

Webhooks automatically update user license tiers based on payment events:

  • Payment success → Upgrade tier
  • Payment failure → Mark as past due
  • Subscription cancelled → Downgrade to FREE

⚠️ Development Mode

Without STRIPE_WEBHOOK_SECRET, the system runs in development mode with reduced security. This is fine for testing but not recommended for production.
