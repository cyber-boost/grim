GRIM REST API Documentation

Programmatic access to the unified data protection ecosystem

The GRIM REST API provides programmatic access to all Grim functionality. Built with Flask and designed for automation, integration, and monitoring.

📋 Overview 🔐 Authentication 🏥 Health Check 💾 Backups 🧠 AI Analysis ⚙️ System

📋 API Overview

Base URL

https://grim.so/api/v1

Response Format

All API responses follow a consistent JSON structure:

{
  "success": true,
  "data": { ... },
  "message": "Operation completed successfully",
  "timestamp": "2025-01-18T14:30:00Z"
}

Quick Start

# Check API health
curl https://grim.so/api/v1/health

# Get backup list with authentication
curl -H "Authorization: Bearer YOUR_API_KEY" \
     https://grim.so/api/v1/backups

🔐 Authentication

All API endpoints require authentication using API keys or JWT tokens.

API Key Authentication

Include your API key in the Authorization header:

curl -H "Authorization: Bearer YOUR_API_KEY" \
     https://grim.so/api/v1/backups

JWT Token Authentication

For user-specific operations, use JWT tokens:

curl -H "Authorization: Bearer YOUR_JWT_TOKEN" \
     https://grim.so/api/v1/user/profile

Get Configuration

     https://grim.so/api/v1/config/backup

    "disk_usage": "45%",

Get System Logs

GET
/api/v1/logs

Query Parameters

  • level - Log level (info, warn, error)
  • limit - Number of log entries (default: 100)
  • since - ISO timestamp for filtering

⏱️ Rate Limits

API rate limiting and usage guidelines.

Standard Limits

  • 1000 requests per hour per API key
  • 100 requests per minute for high-frequency endpoints
  • 10 concurrent connections per API key

Rate Limit Headers

X-RateLimit-Limit: 1000
X-RateLimit-Remaining: 847
X-RateLimit-Reset: 1642518000

Enterprise Limits

  • 10,000 requests per hour for enterprise accounts
  • 1000 requests per minute for high-frequency endpoints
  • 100 concurrent connections per API key
  • Priority support and dedicated infrastructure

📚 SDKs and Libraries

Official and community libraries for integrating with the GRIM API.

Python SDK

pip install grim-api-python

from grim_api import GrimClient

client = GrimClient(api_key="YOUR_API_KEY")
backups = client.backups.list()
health = client.health.get()

JavaScript SDK

npm install grim-api-js

import { GrimClient } from 'grim-api-js';

const client = new GrimClient('YOUR_API_KEY');
const backups = await client.backups.list();
const health = await client.health.get();

Go SDK

go get github.com/grim-project/grim-api-go

import "github.com/grim-project/grim-api-go"

client := grim.NewClient("YOUR_API_KEY")
backups, err := client.Backups.List()
health, err := client.Health.Get()
