# Grim Data Scythe Logos

This directory contains all the extracted SVG logo variations for the Grim Data Reaper system.

## Logo Files

### 1. `grim-logo-primary.svg`
- **Type**: Primary horizontal logo
- **Size**: 280x80px
- **Use**: Main branding, headers, business cards, general use
- **Features**: Full color with gradients, glow effects, detailed data streams being cut

### 2. `grim-logo-icon.svg`
- **Type**: Icon only (square)
- **Size**: 100x100px
- **Use**: Favicons, app icons, social media avatars, compact spaces
- **Features**: Scythe only, no text, perfect for square applications

### 3. `grim-logo-stacked.svg`
- **Type**: Stacked vertical layout
- **Size**: 120x140px
- **Use**: Vertical layouts, mobile screens, narrow spaces
- **Features**: Scythe centered above text, optimized for height

### 4. `grim-logo-light.svg`
- **Type**: Light background variant
- **Size**: 280x80px
- **Use**: Documentation, print materials, light backgrounds
- **Features**: Darker color palette for contrast on light surfaces

### 5. `grim-logo-monochrome.svg`
- **Type**: Single color version
- **Size**: 280x80px
- **Use**: Embroidery, etching, stamps, single-color applications
- **Features**: All elements in #8b4513 (saddle brown)

### 6. `grim-logo-animated.svg`
- **Type**: Animated version
- **Size**: 280x80px
- **Use**: Website headers, loading screens, interactive elements
- **Features**: Animated data streams and cutting effects

## Design Concept

The Grim logo features a **scythe cutting through data streams**, symbolizing:
- **Data Protection**: The scythe eliminates data loss
- **Precision**: Surgical cutting of threats and vulnerabilities
- **Power**: Strong, reliable backup and protection system

## Color Palette

- **Primary Brown**: #8b4513 (Saddle Brown)
- **Accent Gold**: #b8860b (Dark Goldenrod)
- **Highlight Gold**: #daa520 (Goldenrod)
- **Dark Brown**: #654321 (Dark Brown)
- **Light Brown**: #cd853f (Peru)

## Usage Guidelines

### Primary Logo
- Use for main branding, headers, business cards
- Maintain aspect ratio (3.5:1)
- Minimum size: 140x40px

### Icon Only
- Perfect for social media, favicons, app icons
- Always use square format
- Minimum size: 32x32px

### Stacked Version
- Use for vertical layouts, mobile screens
- Maintain aspect ratio (6:7)
- Minimum size: 60x70px

### Light Background
- Use on white/light backgrounds
- Provides better contrast
- Same usage as primary logo

### Monochrome
- Single-color applications
- Embroidery, etching, stamps
- Same usage as primary logo

### Animated
- Website headers, loading screens
- Interactive elements
- Same usage as primary logo

## Technical Specifications

- **Format**: SVG (Scalable Vector Graphics)
- **ViewBox**: Optimized for each variant
- **Gradients**: Linear gradients for depth
- **Animations**: SMIL animations for interactive version
- **Typography**: Arial Black for main text, monospace for tagline

## Browser Support

- **Modern Browsers**: Full support for all features
- **Gradients**: Supported in all modern browsers
- **Animations**: Supported in most modern browsers
- **Fallback**: Graceful degradation for older browsers
